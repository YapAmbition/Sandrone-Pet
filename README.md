## 下载与安装

1. 前往仓库的 [Releases](https://github.com/YapAmbition/Sandrone--Pet/releases/latest) 页面。
2. 下载 `Hissy-Sandrone-macOS.zip`，不要下载 GitHub 自动生成的 `Source code`。
3. 解压后，可以将 `哈气桑多涅.app` 拖入“应用程序”文件夹，然后双击打开。

### macOS 拒绝打开时

当 macOS 提示“无法验证开发者”或“无法检查是否包含恶意软件”时：

1. 确认应用下载自本仓库的 Releases 页面。
2. 在 Finder 中右键点击 `哈气桑多涅.app`，选择“打开”，再在弹窗中确认“打开”。
3. 如果仍然被拦截，进入“系统设置 → 隐私与安全性”，在安全提示旁点击“仍要打开”，然后按系统提示确认。

通常只需在首次启动时完成上述操作，无需关闭 macOS 的系统安全功能。

## 使用

1. 点击宠物会挥爪，双击会跳跃，拖动可改变位置。
2. 菜单栏中的“🐾”可以暂停移动、触发动作、调整大小、开启点击穿透或退出。
3. 也可以右键宠物选择“退出哈气桑多涅”，或从 Dock 中退出。

“标准 100%”对应旧版的 75% 尺寸；小、大和超大选项也会相对新标准尺寸按比例缩放。

菜单栏的 `🐾` 和宠物右键菜单都提供“使用帮助…”，可在应用内离线查看基本功能。

哈气动作会持续约 3 秒并带有轻微抖动。跳跃采用重力抛物线，并按当前宠物尺寸计算高度：起跳快、上升减速、下落加速，再落回原位。

## 逗猫互动

- 在她附近快速来回晃动鼠标，她会盯住鼠标、短暂蓄力，然后横向扑过去。
- 扑到鼠标后会露出得意脸；鼠标及时躲开，她扑空后会生气哈气。
- 不想被突然扑击时，可以在菜单栏关闭“自动扑向鼠标”。
- 短时间内连续戳她三次，她会不耐烦地哈气。
- 捕猎成功后会播放独立的闭嘴、半眯眼“得意脸”动画；菜单栏和宠物右键菜单也可以手动触发“得意一下”。
- 不论通过哪种方式触发，得意时都会显示“多涅多涅~”，哈气时都会显示“哈?~~”。新动作会立即替换已有台词气泡。

## 显示模式

菜单栏的“宠物显示”提供三种会被记住的模式：始终显示、隐藏宠物，以及前台应用进入 macOS 全屏空间时自动隐藏。自动模式会在离开全屏后重新显示宠物，不需要辅助功能权限。

这三种显示模式也可以直接右键宠物选择。应用不注册字母快捷键，所有操作均通过宠物右键菜单、菜单栏或 Dock 完成。

点击穿透开启后，宠物本体不再接收鼠标事件；仍可从菜单栏关闭点击穿透。

## 活动性

菜单栏或宠物右键菜单可选择三种会被记住的活动性：默认模式约 65% 时间待机，活泼模式约 35% 时间待机，安静模式则不再自主走动。安静模式下仍会看向鼠标并响应逗猫和手动动作。

## 系统要求

- macOS 13 或更新版本
- Apple Silicon 或 Intel Mac

## 本地重新构建

```bash
chmod +x build.sh
./build.sh
```

只需安装 Apple Command Line Tools，无需完整 Xcode。
